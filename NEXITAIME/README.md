GitHub Pages `/nexitaime/` 配下で公開しやすいPWA構成にしました。

- 主見出し: 「上越で、何をする？」
- 説明: 「イベントと交通を一緒に見て、今から本当に行ける候補だけを提案します。」
- ブランドコピー: 「AIで、次の時間を見つけよう。」
- 上越らしい観光イメージを背景に配置
- NEXITAIMEのAだけ赤
- `Powered by AXCEL MODE NEXIT` に統一

### GitHub Pages 公開
1. このフォルダ内容を公開リポジトリの `/nexitaime/` 相当へ配置
2. GitHub Pages を有効化
3. Actions に `contents: write` 権限を許可
4. `Update Joetsu events` を一度手動実行し、`events_auto.json` が生成されることを確認

### 制限事項
- イベント自動取得は公式サイトHTML変更の影響を受けるベストエフォート方式。取得失敗時は既存 `events.json` にフォールバック。
- バスのアプリ内実時刻計算は現時点で上越大通り線の主要区間と佐渡汽船連絡バスのみ。その他路線は上越バスロケへの導線を提供。
- 料金不明イベントは予算指定時も除外せず「料金要確認」とする。

## Beta1.0 営業時間・休館日判定強化

候補生成時に以下を考慮します。

- `opening_hours`
- `closed_weekdays`
- `closed_dates`
- `special_hours`
- `last_entry`
- `last_order`
- `seasonal`
- `always_open`
- `daylight_only`

改善点:
- 営業開始前に着く場合は、営業開始まで待ってから滞在開始として計算
- 閉館時刻より前に帰路へ出られるなら、滞在時間を短縮して候補を残す
- 最終入館・ラストオーダーに間に合わない候補は除外
- 特定日の臨時休業・特別営業時間に対応
- 季節営業・冬季休業等の期間指定に対応
- 営業時間未登録の屋内施設は従来どおり「営業時間要確認」と表示

`data/availability-schema.example.json` は記述例です。
実施設の営業時間は推測せず、公式情報を確認して投入してください。


## Beta1.0 混雑・予約推奨表示

結果カードに、リアルタイム混雑を装わない注意表示を追加しました。

対応:
- `reservation_required: true` → 「予約必要」
- `reservation_recommended: true` → 「予約推奨」
- `busy_hours: ["11:00-13:00"]` → 指定時間帯の混雑注意
- `crowding_note` → 運営者確認済み等の補足表示
- 開催中/まもなく開始のイベント → イベント時間帯の混雑注意
- 飲食カテゴリ → 昼・夜の一般的ピーク時間帯を目安表示
- カフェカテゴリ → 午後の一般的混雑時間帯を目安表示
- 休日の観光・イベント系候補 → 休日混雑の注意表示

表示には必ず
「混雑表示はリアルタイム情報ではなく、登録情報と時間帯・曜日からの目安」
と明示します。

`data/crowding-schema.example.json` は記述例です。
実施設固有の予約推奨・混雑情報は推測せず、公式情報や運営者確認に基づいて投入してください。
