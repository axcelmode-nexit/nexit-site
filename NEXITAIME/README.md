# NEXITAIME 〜上越版〜 v12

v11の機能を維持したまま、トップ画面を上越観光イラスト調へ変更し、
GitHub Pages `/nexitaime/` 配下で公開しやすいPWA構成にしました。

## デザイン変更
- 主見出し: 「上越で、何をする？」
- 説明: 「イベントと交通を一緒に見て、今から本当に行ける候補だけを提案します。」
- ブランドコピー: 「AIで、次の時間を見つけよう。」
- 上越らしい観光イメージを背景に配置
- NEXITAIMEのAだけ赤
- `Powered by AXCEL MODE NEXIT` に統一

## PWA / GitHub Pages
- `manifest.json`
- `sw.js`
- `.nojekyll`
- 相対パス構成
- `https://axcelmode-nexit.jp/nexitaime/` 配下を想定

## 既存機能
- GPS
- 天気
- イベント
- 電車 / バス
- 公共交通全般
- 自家用車 / カーシェア / レンタカー / タクシー
- 徒歩 / レンタル自転車
- 実在移動拠点
- 地図
- 最寄り拠点
- 拠点までの徒歩時間を含む所要時間判定

## 公開時
GitHub Pages側の公開ディレクトリにこのフォルダ内容を `/nexitaime/` として配置してください。
HTTPS配信時に位置情報/PWAが利用できます。

## v18: おまかせ全移動手段比較
- おまかせ時に自家用車 / カーシェア / レンタカー / 電車 / バス / タクシー / 徒歩 / レンタル自転車を横断比較
- 公共交通全般の個別選択は電車とバスを比較
- 30分以上滞在でき、戻り余裕を確保できる候補だけを表示
- 滞在可能時間、戻り余裕、到着時刻で上位3案を選定
- カーシェア / レンタカー / レンタル自転車は最寄り拠点までの徒歩時間を加算
- タクシーは営業所まで歩かず、配車待ち時間のみ既存ロジックで加算
- 結果カードに採用移動手段と「この案の理由」を表示
- 特定の移動手段を選んだ場合は、その手段だけで従来どおり判定

### 注意
カーシェア空車、レンタカー在庫、タクシー配車、自転車残数はリアルタイム未連携です。


## v20 public beta
- 予算フィルタ: 0円 / 〜1,000円 / 〜3,000円 / 気にしない
- 同行者フィルタ: ひとり / カップル / 家族 / 子連れ
- 天気連動: 雨・雪では屋内候補を優先、屋外候補の順位を下げる
- 営業/開催時間判定: 終了済みイベントを候補から除外
- 結果理由に天気・同行者・料金情報を反映
- events_auto.json が存在すれば自動更新イベントを優先し、無ければ events.json を使用
- GitHub Actions (`.github/workflows/update-events.yml`) で上越観光Naviを毎朝ベストエフォート更新
- bus_routes.json に上越バスロケ対応路線一覧を追加

### GitHub Pages 公開
1. このフォルダ内容を公開リポジトリの `/nexitaime/` 相当へ配置
2. GitHub Pages を有効化
3. Actions に `contents: write` 権限を許可
4. `Update Joetsu events` を一度手動実行し、`events_auto.json` が生成されることを確認

### 制限事項
- イベント自動取得は公式サイトHTML変更の影響を受けるベストエフォート方式。取得失敗時は既存 `events.json` にフォールバック。
- バスのアプリ内実時刻計算は現時点で上越大通り線の主要区間と佐渡汽船連絡バスのみ。その他路線は上越バスロケへの導線を提供。
- 料金不明イベントは予算指定時も除外せず「料金要確認」とする。
